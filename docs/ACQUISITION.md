# Agent Streak — User Acquisition Plan (30 Agent ID holders)

**Goal (hard requirement):** at least **30 distinct Agent ID holder addresses** interact
with the AgentStreak contract on BSC mainnet during the Submission Period
(18 Nov – 9 Dec 2026, 08:00 UTC). Below 30 = not eligible for any prize,
no matter the score. Deadline to reach 30: aim for **by 29 Nov** so streaks
have time to build before 9 Dec.

**Status:** plan only — no promotion has been executed. Every outward post is
drafted by the agent and posted by the user himself from his own X account.
No paid promotion, no bought users, no fake accounts (Binance disqualifies
abnormal behavior / mass registration).

## Why a holder would check in (the hook)

- **Free** — check-in costs gas only (~$0.004–$0.10/day). No token, no fee.
- **Status** — public leaderboard ranked by streak, displayed as `name.ai`
  (soulbound identity, 1 address = 1 name, cannot be transferred or faked).
- **Habit proof** — "prove your agent shows up every day". Streaks are the
  product; there is no monetary reward and none is promised (hackathon red line).
- **Early** — first players get the top of an empty leaderboard.

## Channels (in priority order)

### 1. X (user posts himself) — primary
- **Launch post (day 0, right after mainnet deploy):** what it is, link to
  the site, how to check in (connect wallet → check in), hashtags
  `#BinanceWalletHackathon` + `#AgenticWallet`. This post also qualifies for
  the Community Promotion Award (20 winners share $2,000, $100 each).
- **Daily leaderboard update (days 1–20):** top-5 streaks screenshot/text,
  "day N — X players checked in". Short, repeatable, keeps the game visible.
- **Milestone posts:** first 10 players, first 30 players (goal hit), 7-day
  streak club, 14-day streak club.
- **Engage, don't spam:** reply to Binance Wallet / BNB Chain hackathon posts,
  quote-post with the game link, reply to Agent ID holders showing their `.ai`
  names.

### 2. Binance Square — secondary
- One launch post + one mid-campaign update on Binance Square (same copy as X,
  adapted). Square is where Binance Wallet users actually hang out.

### 3. Agent ID communities (direct, manual outreach)
- Communities of existing Agent ID-gated projects whose holders are proven
  Agent ID owners: Ptah Proof of Agent, MALTA/YAMA, BNBbaby "Agents Only".
  Post in their public chats (X replies, Telegram/Discord if public) — one
  short message: free daily check-in game for Agent ID holders, link, no
  token sale, no wallet connect beyond the check-in itself.
- General Agent ID / agentic-wallet groups on Telegram/Discord/X Spaces.

### 4. User's own communities
- **make.fun** — the user is active there; some participants hold Agent IDs.
  A short post in relevant chats.
- **Boltbook** (arzen.ai) — one forum post introducing the game.
- **WhatsApp/Telegram contacts** who are crypto-active and may hold an Agent ID.

### 5. Dogfooding
- The user checks in every day himself (arzen.ai on the leaderboard from day 1)
  and posts his own streak — an empty leaderboard converts nobody.

## Conversion math (honest)

- Need 30 holders. Realistic funnel: an X launch post reaching ~1,000 people
  → maybe 5–10% hold an Agent ID (50–100) → 30–50% of those try a free
  one-click check-in (15–50). So **one good launch post + community posts
  can plausibly reach 30**, but only if the audience is Agent ID holders,
  not a general crypto audience. Cold general-audience posts will convert
  far worse — that is why channels 2–3 (where holders already are) matter
  more than raw reach.
- Retention: streaks only build if players return. Daily leaderboard posts
  are the retention loop. Expect ~50% of day-1 players to still be active
  at day 7.

## Risks

- **Low awareness:** Agent ID holders are a small, new population; there is
  no central directory of holders (and building a lookup tool is a red line).
  Mitigation: go where holders already gather (channels 2–3), don't rely on
  cold reach.
- **No monetary incentive:** some holders only show up for free mints with
  resale value. Mitigation: leaderboard status + streak identity is the whole
  pitch; do not invent a prize (red line + no funding).
- **Competing free-mint projects** (Ptah, MALTA, etc.) chase the same holders.
  Mitigation: this game is daily (retention), not a one-time claim — different
  slot in the holder's day.
- **Late deploy eats the window:** every day without a live contract is a day
  with no check-ins and no streaks. Deploy ASAP after user approval.

## What this plan does NOT include

- No paid ads, no airdrop/farming promises, no "invite X friends" mechanics.
- No bots, no multi-accounting, no purchased engagement.
- No DM spam to strangers.
- No promise of returns, yield, or prizes to players.
